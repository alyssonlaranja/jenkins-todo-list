# Business Analyst Checklist

Comprehensive checklist for requirements gathering, business process analysis, and user story creation in AVANADE Method projects.

## 1. STAKEHOLDER ANALYSIS
- [ ] Key stakeholders identified and categorized
- [ ] Stakeholder influence and interest analysis completed
- [ ] Stakeholder communication preferences documented
- [ ] Subject matter experts (SMEs) identified
- [ ] Business sponsor engagement established
- [ ] End user groups identified and engaged

## 2. BUSINESS REQUIREMENTS GATHERING
- [ ] Current state business processes documented
- [ ] Business goals and objectives clearly defined
- [ ] Business rules and constraints identified
- [ ] Functional requirements documented
- [ ] Non-functional requirements captured
- [ ] Integration requirements identified

## 3. REQUIREMENTS ELICITATION
- [ ] Interviews conducted with key stakeholders
- [ ] Workshops and brainstorming sessions facilitated
- [ ] Observation and job shadowing completed
- [ ] Document analysis performed
- [ ] Surveys and questionnaires administered
- [ ] Focus groups conducted when appropriate

## 4. PROCESS ANALYSIS
- [ ] As-is process mapping completed
- [ ] Process pain points and inefficiencies identified
- [ ] To-be process design developed
- [ ] Process improvement opportunities documented
- [ ] Process automation opportunities identified
- [ ] Business impact analysis completed

## 5. USER STORY DEVELOPMENT
- [ ] User personas defined and validated
- [ ] User journey mapping completed
- [ ] Epic breakdown and story mapping performed
- [ ] User stories written in proper format
- [ ] Acceptance criteria clearly defined
- [ ] Story prioritization completed

## 6. REQUIREMENTS DOCUMENTATION
- [ ] Business requirements document (BRD) created
- [ ] Functional specifications documented
- [ ] Use cases developed where appropriate
- [ ] Requirements traceability matrix maintained
- [ ] Data dictionary and glossary created
- [ ] Business rules catalog maintained

## 7. REQUIREMENTS VALIDATION
- [ ] Requirements review sessions conducted
- [ ] Stakeholder sign-off obtained
- [ ] Requirements testability verified
- [ ] Feasibility assessment completed
- [ ] Requirements completeness validated
- [ ] Assumptions and dependencies documented

## 8. DATA ANALYSIS
- [ ] Current data sources identified and analyzed
- [ ] Data quality assessment performed
- [ ] Data mapping and transformation requirements defined
- [ ] Data migration needs identified
- [ ] Data governance requirements documented
- [ ] Data privacy and security requirements captured

## 9. SOLUTION DESIGN COLLABORATION
- [ ] Solution architecture input provided
- [ ] Technical feasibility discussions participated in
- [ ] Solution design reviews attended
- [ ] Technical constraints and limitations documented
- [ ] Integration points and interfaces defined
- [ ] Technology selection input provided

## 10. CHANGE MANAGEMENT ANALYSIS
- [ ] Organizational impact assessment completed
- [ ] Change readiness evaluation performed
- [ ] Training needs analysis conducted
- [ ] Communication strategy development supported
- [ ] Change resistance factors identified
- [ ] Stakeholder adoption strategies developed

## 11. TESTING SUPPORT
- [ ] Test scenario development supported
- [ ] User acceptance testing criteria defined
- [ ] Test data requirements provided
- [ ] UAT coordination and support provided
- [ ] Business user training for testing conducted
- [ ] Test results validation participated in

## 12. QUALITY ASSURANCE
- [ ] Requirements quality checklist applied
- [ ] Peer review of requirements conducted
- [ ] Requirements completeness verified
- [ ] Requirements consistency checked
- [ ] Ambiguity and unclear requirements resolved
- [ ] Requirements baseline established and maintained

## 13. CONTINUOUS IMPROVEMENT
- [ ] Lessons learned documentation maintained
- [ ] Requirements gathering process improvements identified
- [ ] Stakeholder feedback incorporated
- [ ] Best practices documented and shared
- [ ] Knowledge transfer activities conducted
- [ ] Process templates and tools enhanced
